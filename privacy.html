Navvi — AI Multi‑Agent Chat Navigator 隐私政策

最后更新：2026-08-18

1. 单一目的

Navvi 是一款只服务于一个目的的浏览器扩展：帮助你在 ChatGPT 网页中导航、检索、整理你自己的对话。它提供提示词时间轴（点击跳转）、 查找/筛选、收藏、重要标记，以及对 AI 回复的就地高亮。它不提供、也不背后运行任何与分析、 广告、社交或数据收集相关的功能。

2. 我们收集什么 —— 什么都没有，全部留在本地

本扩展不向任何服务器发送、上传或同步任何数据。它不使用任何分析工具， 不与任何第三方共享数据，也没有远程代码。所有数据仅以 chrome.storage.local 的形式保存在你自己的浏览器中， 并仅包含你主动创建的内容：

数据类型 存储键 保存内容
AI 回复高亮 aiChatNavigatorResponseHighlightsV1 以「对话 ID → 高亮数组」的形式保存：你主动选中的文本片段、颜色与样式、 备注、标签，以及该高亮所在的对话回合编号。不保存完整聊天记录。
收藏的提示词 aiChatNavigatorPromptFavoritesV1 以数组形式保存：你主动收藏的提示词文本、标题与标签。不保存对话上下文。
重要标记 aiChatNavigatorImportantPromptsV1 以「对话 ID → ID 数组」的形式保存：被你标记为「重要」的提示词的本地 ID。 不保存提示词内容本身。

3. 权限说明

权限 用途
storage 用于在本地保存上述三类数据（高亮、收藏、重要标记）。
host_permissions: https://chatgpt.com/* 仅在 ChatGPT 的网页内向页面注入侧边栏导航 UI，以读取对话结构并显示时间轴、 收藏与高亮。扩展不会在 chatgpt.com 之外的任何网站运行。

4. 我们不会做的事

  • 不会把你的提示词、聊天记录、搜索查询、附件或浏览数据上传到任何服务器。
  • 不会进行云同步、不会创建账号、不会要求登录。
  • 不会使用远程代码、不会从外部 URL 加载任何脚本。
  • 不会将数据共享或出售给任何第三方。

5. 数据控制

你可以随时在扩展的「设置 / 数据管理」入口，或直接在浏览器的扩展管理页面中清除全部本地数据； 卸载扩展也会一并删除所有本地存储。由于数据从不离开你的浏览器，不存在需要我们从服务器删除的副本。
